# Dependabot Ecosystem: Nimble & Atlas (Nim)

This directory contains the proposed implementation for the **Nimble** (and Atlas) package ecosystem for the [Nim programming language](https://nim-lang.org/).

## Overview

- **Ecosystem name**: `nimble`
- **Supported Package Managers**: `nimble`, `atlas`
- **Manifests**: `*.nimble`, `atlas.config`
- **Lockfiles**: `nimble.lock`, `atlas.lock`
- **Primary Registry**: `https://raw.githubusercontent.com/nim-lang/packages/master/packages.json`

## Documentation & RFC
See [RFC 0001: Nimble Ecosystem Proposal](../docs/rfcs/0001-nimble-ecosystem.md) for full design, cooldown implementation, declarative parsing invariants, and rollout phases.
